An RSS / Atom reader for Linux

OPML in, articles out.

A three-column reader for the feeds you already have. Local OPML, no accounts, no daemon, no cloud. Subscribe quietly.

Download AppImage .deb for Ubuntu / Debian
v0.2.0 · Linux x86_64 · Free & open source
Features

Built for the OPML you already have.

Three columns

Feeds → items → article

The reader shape that worked in 2005 and still works. No hamburger menu hiding it.

.opml

Your file, your subscriptions

One OPML file per window. Add, edit, export — the same file that any other reader can import.

Local

No accounts

No login, no sync server, no companion mobile app. Just RSS / Atom and a window.

Pull-only

No daemon

Feeds refresh when you ask them to or when the app is open. Closed app, zero background activity.

Tauri · Rust

Native Linux

Small binary, real file associations, no Electron, ships as AppImage and .deb.

Help → Check for updates

In-app updater

Pull-only, no boot-time check. AppImage replaces itself on confirm; .deb routes you to apt.

Install

Two files. One minute.

The shared krill install script fetches the latest .deb from GitHub Releases and registers it via apt so it survives system upgrades.

Or build from source: pnpm install && pnpm tauri build.

One-line installer

curl -fsSL https://raw.githubusercontent.com/krill-software/.github/main/install.sh \
  | sh -s rss-reader

AppImage · portable

chmod +x RSS.Reader_0.2.0_amd64.AppImage
./RSS.Reader_0.2.0_amd64.AppImage feeds.opml
